# Overview

This is a project focused on demonstrating MCP technology and its applications through Claude Desktop. It includes a live hosted website that allows users to log in and explore a collection of art pieces. It provides users with a way to also favorite/like their art pieces and saves it to the database.

## How To Run Locally

1. Clone the repository to your local machine.
2. Navigate to the root directory and install dependencies using `npm install`.
3. Build it with `npm run build`.
4. Start the development server with `npm run dev`.
5. Open your browser and go to `http://localhost:5173` to view the application.
- (optional) If you want to visit the Live website instead its at https://mcp-project-471a6.web.app/Home
